# Charlie Training V1

Web-app mobile-first pour suivre tes séances.

## Inclus
- Push / Pull / Cardio / Legs / Upper
- charges et références déjà préchargées
- mode séance série par série
- RIR + échec
- timer de repos
- bouton « Machine prise »
- semaine + objectifs quotidiens
- historique de références
- mode Nolan : normal, mal dormi, 40 min max, salle blindée
- sauvegarde locale dans le navigateur

## Lancer
```bash
npm install
npm run dev
```
Puis ouvre http://localhost:3000

## Déployer sur Vercel
1. Mets ce dossier sur GitHub.
2. Importe le repo dans Vercel.
3. Aucun secret n’est nécessaire pour cette V1.
